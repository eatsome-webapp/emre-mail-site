Mailsome

Privacy policy

Last updated: 22 October 2026

Who uses Mailsome

Mailsome is a personal desktop mail client for macOS. It is used only by its owner, for his own mail accounts. It is not offered to other people.

Google user data it accesses

With the owner's consent, Mailsome uses the Gmail API to read, organise, draft and send mail in his Gmail account, and reads his name and email address to identify the account.

How the data is used

  • To show, search and organise the owner's mail in the app.
  • To sort incoming mail, summarise it and prepare reply drafts for the owner.
  • To send mail when the owner sends it, or within automation rules he has explicitly activated.

Google user data is never used for advertising, never sold and never used to train general-purpose AI models.

Storage

Mail is stored in a local database on the owner's Mac. Sign-in tokens are kept in the macOS Keychain. Mailsome has no server of its own and does not upload mail anywhere except as described below.

Sharing

When the owner turns on AI assistance for an account, the content of messages from that account is sent to Anthropic's Claude API to analyse them and write drafts. Anthropic processes this data under its commercial API terms, which do not allow it to be used for training its models. No other parties receive Google user data.

Limited Use

Mailsome's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data

Removing an account in Mailsome deletes its local mail and tokens. Access can also be revoked at any time at myaccount.google.com/permissions.
